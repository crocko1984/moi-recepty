# Мои рецепты

Статическое PWA-приложение с 20 рецептами для аэрогриля Tefal, поиском, фильтрами, избранным, случайным подбором и добавлением собственных рецептов на устройстве.

## Общие рецепты

Рецепты из `shared-recipes.json` видны всем посетителям. Рецепты, которые пользователь добавляет через приложение, остаются только на его устройстве, пока владелец не скачает их резервную копию и не заменит ею содержимое `shared-recipes.json` в репозитории.

## Публикация через GitHub Pages

После отправки файлов на GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**.

Сайт будет доступен по адресу: `https://crocko1984.github.io/moi-recepty/`.

Приложение работает без сервера: все файлы, включая сервис-воркер, находятся в корне репозитория. Не добавляйте в него личные записи, ключи или пароли.
