# Мои рецепты

Небольшое статическое PWA-приложение с публичными демонстрационными рецептами.

## Публикация через GitHub Pages

После отправки файлов на GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**.

Сайт будет доступен по адресу: `https://crocko1984.github.io/moi-recepty/`.

Приложение работает без сервера: все файлы, включая сервис-воркер, находятся в корне репозитория. Не добавляйте в него личные записи, ключи или пароли.
